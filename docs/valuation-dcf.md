# Deterministic fundamental valuation (#3)

The `calculate_dcf` agent/MCP tool and authenticated `POST /api/valuation/dcf`
compute an auditable five-year **FCFF** (not FCFE) DCF:

- Financial baseline: positive total-company FCFF, diluted share count,
  net debt (total debt less cash, potentially negative), fiscal date,
  currency, and explicit source URLs. No values are fabricated.
- Exactly three named scenarios `bear`, `base`, `bull` with five growth
  rates, scenario WACC, perpetual terminal growth, and scenario probability.
  Probabilities sum to 1. WACC must exceed terminal growth by >=0.5 points.
- For each year n, FCFF(n) = FCFF(n−1) × (1+growth[n]).
  PV(n) = FCFF(n)/(1+WACC)^n. Gordon terminal value at year five
  is FCFF5 × (1+g)/(WACC−g); terminal PV divided by (1+WACC)^5.
- Enterprise value = sum discounted flows + discounted terminal value.
  Equity value = enterprise value **minus net debt**; intrinsic value per share
  = equity / diluted shares. If equity is nonpositive, refuse a per-share
  valuation rather than implying a negative tradable stock price.
- `calculate_wacc` uses market equity/debt value weighting and interest tax
  shield. `calculate_roic` = NOPAT / *average* invested capital.
- Output includes five year-by-year forecasts, discount factors, present
  values, terminal values, EV/equity bridge, fair value/share and optional
  market-price upside, as well as claimed input evidence URLs.

No source URL guarantees an input was in that filing: review SEC facts/primary
filings and match periods, currencies and GAAP/IFRS concepts first. Inputs and
scenarios are provided assumptions, never auto-generated by the engine. This
is a research model, not personalized advice or authorization to trade.

Example payload (illustrative ONLY; do not treat as NVIDIA facts):

```json
{
  "ticker":"EXAMPLE", "currency":"USD", "period_end":"2026-06-30",
  "source_urls":["https://www.sec.gov/Archives/edgar/data/1045810/"],

  "diluted_shares":1000000000, "market_price":200,
  "scenarios":[

  ]
```
