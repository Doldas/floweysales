# Help and About

Help and About are in the sidebar, near the bottom, for every signed-in user, and in the command palette (Ctrl/⌘ K). They also work in the mobile menu. Both use the same icon, colors and themes as the rest of the app.

## Documentation and AI answers are different things

- **Help** is written documentation. People wrote it, and it changes only when the project changes.
- **The Research Agent** is an AI model. Its answers can be wrong and are labeled as AI-generated. They are never mixed into Help articles.

If you want an answer about your own data, ask the agent and check its sources. If you want to learn how a screen works, read Help.

## The Help page

The Help page lists short articles on the left: getting started, the Research Agent, Agent team, Flows, Markets and the price feed, the Leaderboard, Strategies and backtests, World, the Wealth plan, a glossary and troubleshooting. The search box filters the list by title, summary, keywords and text, and every word you type must match. The page links to the documentation site, https://doldas.github.io/floweysales/, which holds this user guide, and every article ends with a link to its page in the guide.

## The "?" panels

Some pages have a small question mark next to the title: Research Agent, Agent team, Flows, Markets, the Leaderboard and Strategies. It opens the matching Help article in a panel on the right without leaving the page, so your work stays where it was. The panel has links to the full Help page and to the matching page of the user guide. Press Escape or the close button to return to where you were.

## The documentation site

The site has this user guide, an API explorer and links to the code. It uses the same icon, colors and light and dark themes as the app. Each guide page shows when it was last reviewed (in UTC). A search box filters the pages. If something is wrong or missing, use "Report a documentation problem" at the bottom of a page to open an issue.

## About

The About page says what FloweySales is for and shows this build:

- **Version:** the commit the build was made from, or "Development build" when the build has no version information. FloweySales does not guess a version.
- **Built:** the build time in UTC, when known.
- **License:** MIT, with a link to the license file.
- **Links:** the documentation site, the GitHub repository, the issue tracker and releases.

The build information comes from the server and is shown only to signed-in users.
