Reference / API surfaces

API & provider catalog.

Which endpoints work in the FloweySales application, which exist as MCP tools, and which are only documented by the external data provider?

The catalog is an inventory of verified code surfaces and known public research endpoints. It is not a complete export of every private, paid or order-related provider API. An implemented endpoint does not guarantee that the provider answers for every symbol or subscription.

01 / Application

REST APIs in the application

Catalog as JSON ↗

Example base URL: http://localhost:8080. With authentication on, a session cookie is used. Do not expose the backend to the internet without HTTPS, access control and hardening.

02 / AI tools

MCP server tools

JSON-RPC / tools/list

The MCP server advertises the same tools as the AI agent through tools/list. What can actually be called is limited by backend access, permissions and provider keys. See also GET /api/ai/tools for the schemas.

03 / Providers

External provider endpoints

Official / unofficial

The allowlisted read operations can be called through both GET /api/provider/research and the MCP tool get_provider_research. There is no arbitrary URL forwarding, no API key in the browser and no private order APIs.

04 / Quick start

Example calls

The examples target your own FloweySales backend and assume you are signed in with the right permissions. API keys such as FINNHUB_API_KEY are configured on the server only.

Historical quarters

GET /api/financials?symbol=NVDA&provider=YAHOO&from_year=2020&to_year=2025

Finnhub company profile

GET /api/provider/research?provider=FINNHUB&operation=company_profile&symbol=NVDA

Binance order book

GET /api/provider/research?provider=BINANCE&operation=order_book&symbol=BTCUSDT

MCP tool call (JSON-RPC)

{"jsonrpc":"2.0","id":1,"method":"tools/call","params":{"name":"get_provider_research","arguments":{"provider":"FINNHUB","operation":"company_peers","symbol":"NVDA"}}}
05 / Sources & safety

Documentation and limits

The provider lists are compiled from official documentation where it exists, and from clearly marked third-party sources otherwise. Always check the current license, rate limits, history, currency and subscription before production use. Brokerage login, BankID, order placement and account data flows are not part of the provider gateway.
