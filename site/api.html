REFERENCE / API SURFACES

API & providerkatalog.

Vilka endpoints fungerar i FloweySales-applikationen, vilka finns som MCP-verktyg och vilka är bara dokumenterade hos den externa dataleverantören?

Katalogen är en inventering av verifierade kodytor och kända publika forskningsendpoints, inte en komplett export av leverantörernas alla privata, betalda eller orderrelaterade API:er. En implementerad endpoint är inte en garanti för att leverantören svarar för varje symbol eller abonnemang.

✓ Tillgänglig i FloweySales ○ Endast hos leverantör ! Inofficiell / opt-in
Katalogen kunde inte laddas. Se docs i GitHub och rå JSON-katalog.
01 / APPLICATION

REST-API:er i applikationen

Katalog som JSON ↗

Exempel bas-URL: http://localhost:8080. Med inloggning används session cookie. Öppna inte backend mot internet utan HTTPS, accesskontroll och härdning.

02 / AI TOOLS

MCP-serverns verktyg

JSON-RPC / tools/list

MCP-servern annonserar samma verktyg som AI-agenten via tools/list; det som faktiskt kan anropas begränsas av backend-åtkomst, rättigheter och leverantörsnycklar. Se även GET /api/ai/tools för scheman.

03 / PROVIDERS

Externa leverantörers endpoints

OFFICIAL / UNOFFICIAL

De nya whitelistade läsoperationerna kan anropas genom både GET /api/provider/research och MCP-verktyget get_provider_research. Ingen godtycklig URL-forwarding, API-nyckel i webbläsaren eller privata order-API:er ingår.

04 / QUICK START

Exempel på anrop

Exemplen gäller den egna FloweySales-backenden och förutsätter korrekt inloggning/behörighet. API-nycklar som FINNHUB_API_KEY konfigureras bara på servern.

Historiska kvartal

GET /api/financials?symbol=NVDA&provider=YAHOO&from_year=2020&to_year=2025

Finnhub bolagsprofil (NY)

GET /api/provider/research?provider=FINNHUB&operation=company_profile&symbol=NVDA

Binance orderdjup (NY)

GET /api/provider/research?provider=BINANCE&operation=order_book&symbol=BTCUSDT

MCP-verktygsanrop (JSON-RPC)

{"jsonrpc":"2.0","id":1,"method":"tools/call","params":{"name":"get_provider_research","arguments":{"provider":"FINNHUB","operation":"company_peers","symbol":"NVDA"}}}
05 / SOURCES & SÄKERHET

Dokumentation och begränsningar

Leverantörslistorna är sammanställda från officiella dokument där sådana finns och tydligt utmärkta tredjepartskällor annars. Kontrollera alltid aktuell licens, rate limits, historik, valuta och abonnemang före produktionsanvändning. Flöden för depåinloggning, BankID, orderläggning och kontouppgifter är inte del av den nya provider-gatewayen.
